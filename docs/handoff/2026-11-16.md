## What the PR 26 traces show

Counted from the six saved Phase 1 runs (headline = 73 tuning claims, conflict group out).

1. **The final check removed mostly correct verdicts.** In Step 4 the code had reached
   True or False on 32 claims, 25 of them matching the label. The final check published 8
   and withheld 24, of which 17 were correct. Split by condition over Steps 2 to 4: the two
   prose conditions (sentence unsupported, sentence bundles facts) withheld 23 correct and
   6 wrong decisions; the decision question withheld 20 wrong and 12 correct.
2. **One run cannot show a small change.** The 95% interval of one 73-claim run is about
   11 points either side. Across the six runs, 23 of 73 claims had passage readings that
   leaned True in one run and False in another. Of the step-to-step differences, only
   Step 4 (-16) is clearly larger than that noise; Step 2 (+11) is at its edge.
3. **Passage reading did not move.** Counting only "more supporting than contradicting
   passages" gives 35 to 41 of 73 in every run. The steps changed which gates fired, not
   what was read.
4. **Comparisons never worked.** In the 13 comparison claims not one operand value passed
   validation in the Nov 16 Nemotron run; the repeated attempts use up the call limit.
5. **Clarification questions were research questions.** 7 to 11 claims per run stopped to
   ask the user things like "Who is John Jumper?"; a different set of claims each run.
6. **The model was chosen before it could be compared.** The Nov 15 comparison ran when
   every model had almost all verdicts withheld, so it measured completion, not accuracy.

## Change 1: only the decision question gates the verdict (bde7613)

A sentence that fails the support or one-fact check is removed from the explanation. If no
sentence passes after the one repair, the decisive cited passages are quoted word for word
and a limitation says so. A decision the check confirmed is not asked again while the
prose is repaired. A decision the check does not confirm is still withheld.
Tests: 519 passed, 1 xfailed; 26 sensitivity mutations detected; ruff clean.

## Change 2: the batch report shows the funnel and the noise (410809f)

`report.md` now has "Where verdicts are lost" (no evidence read, no code decision, code
decided, published, withheld, each with label agreement) and the 95% interval of the run.
`report.csv` gains `evidence_items` and `code_decision`.
